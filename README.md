# REPO-Cenfo

Aplicación web full-stack con frontend, backend y base de datos separados.

## Estructura
- `frontend/`: interfaz de usuario
- `backend/`: API y lógica del servidor
- `database/`: scripts y esquema de la base de datos

# Características
- Plataforma universitaria cuya función principal es registrar documentos, tesis y trabajos académicos
- Permite que los estudiantes siempre los tengan a mano como guía de consulta
- Acceso por roles (administrador, docente y estudiante) con autenticación JWT
- Carga de archivos PDF

#Tecnologias -JS -React -Node.js -Express -ORM -SQL Server
